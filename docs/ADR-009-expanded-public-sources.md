# ADR-009：跨市场公开信源与实际可读性检测

日期：2026-11-09。状态：已实现；实网限制如下。

## 问题与变化

原来的通用问答、许可 Feed 和少数官网不能稳定支持多个国家与行业。没有登记 Feed、站点拒绝自动访问、检索没有结果、当前网络不可达是不同情况，必须分别展示。

在原有7类来源上增加6类无需模型密钥的官方入口，总计13类；官网候选扩展为32个。市场增加英国。按数据覆盖市场隔离默认选择，并在前后端验证；欧洲 TED 与英国 Find a Tender 分开。既有研究快照和用户停用的档案保持不变，新增研究使用新的默认范围。

| 新入口 | 官方文档／用途 | 检索边界 |
|---|---|---|
| 工信部行业公告 | [官方订阅目录](https://www.miit.gov.cn/RRSdy/index.html)；产业公告标题与链接 | 近期目录最多100个链接中匹配8条；不读新闻正文；标题不能证明需求 |
| 日本 METI | [RSS](https://www.meti.go.jp/rss/)、[使用规约](https://www.meti.go.jp/main/rules.html) | 官方近期 Atom 的标题、摘要与日期；最多80项中匹配8项；不是全站搜索 |
| 欧洲 TED | [官方 API 文档](https://docs.ted.europa.eu/ODS/latest/reuse/search-api.html)、[数据复用](https://ted.europa.eu/en/help/data-reuse) | 匿名关键词检索8项；保留买方所在国与公告类型，估值非成交 |
| 英国 Find a Tender | [官方开放采购文档](https://www.gov.uk/government/publications/open-contracting) | 最近14天、最多100条更新公告中筛选8项，披露窗口与分页截断；不声称全库检索 |
| 美国 Federal Register | [官方 API 文档](https://www.federalregister.gov/developers/documentation/api/v1) | 关键词检索最近8项；元数据与摘要；区分草案和生效规则，正式法律文本需另核对 |
| 美国 FDA | [调用文档](https://open.fda.gov/apis/drug/enforcement/how-to-use-the-endpoint/)、[数据许可](https://open.fda.gov/license/) | 食品／药品召回8项；单条召回编号链接，排除地址与 GMDN 字段；召回不等于需求或发生率 |

## 故障处理与报告

- 官网按本地、全球的顺序匹配，最多尝试10个、取得4份有效材料后停止；逐站保留失败原因与市场。仅登记不表示已经核对；robots、不允许AI、身份验证、动态价格等限制继续生效。
- 「检测实际信源」不调用模型、不写入材料和研究报告，仅保存健康与检测摘要。按用户勾选、市场和行业匹配，最多3类并行；尊重来源 backoff，重复检测缓存60秒，登记变更使缓存失效。
- 网络失败、配置缺口、不适用、无匹配、部分成功与缓存复用分别显示。检测条数不是语义相关性或市场强度。
- 正式研究仍做相关性和逐字引用校验；新适配器只允许引用原始字段摘录，禁止把采集器合成的金额标签、边界提示当作机构原话；新材料按政策、采购公告、合同获授、召回、官网方案分别计数。同一采购流程取已检索窗口中的最新公告，同一FDA事件按event_id归为一簇，避免重复产品编号放大独立性。报告明确全球替代方案与本地官网份数，均不代表客户验证。
- 6小时缓存保留原采集时间，按市场与行业许可范围过滤；绝不以缓存冒充本次访问。HTTP限流／暂时不可用继续遵守等待时间。
- 模型商业分析明确：政策不能证明需求、召回不能证明发生率、预算与获授不能冒充实际付款。现有费用与密钥逻辑不变。

## 验收证据与局限

2026-11-09 本机真实请求：Federal Register 返回8项记录，FDA salmon 查询返回8条召回；中国电商／AI查询取得阿里云百炼及A2X、Link My Books、Shopify的4份官网材料，日本会计查询取得Money Forward及3份全球官网材料。部分官网拒绝或网络失败后，仍继续访问其他候选。

同次网络下，工信部、METI、TED、Find a Tender 的请求出现 ECONNRESET。这些入口完成了适配及响应结构／安全边界测试，但尚未通过本机成功读取验收，不能据此称所有来源均可用。当前出口网络、站点策略、Feed窗口和行业相关性均可能限制结果；官方入口数量不等于中国本地客户或成交证据覆盖。

私有实网记录保存在 `.data/acceptance/`，不提交仓库。自动化使用隔离数据和固定响应，测试地区隔离、匿名API参数、查询注入防护、robots/noai/实体拒绝、字段最小化、估值与取消状态、独立失败、健康检测不调用模型、缓存与官网候选切换。界面测试覆盖中国／欧洲／英国选择与用户勾选后的检测结果。
