# ADR-005 — 真实模型运行兼容与任务稳定性

状态：已实施并完成真实联网验收。用户已保存 qwen3.8-flash 的兼容 API 配置。

## 实际发现与处理

- Qwen 混合思考模式在短输出额度下可能没有最终 JSON。结构化任务的自动模式对 Qwen 混合模型发送 enable_thinking=false，提供显式开关。依据阿里云官方混合思考文档：https://www.alibabacloud.com/help/en/model-studio/deep-thinking.md 。没有打印或持久化原始思考过程。
- 输出解析失败也保留供应商返回的 usage、结束原因和请求 ID；无法确认的费用保守保留未知，不宣称免费。
- 模型输出中的中文转述不当作原文事实观察。新增明确的降级校验：逐字摘录必须匹配现存材料，删除不可核验引用；不满足标准的 observation 降为 inference/unknown，没有引用的 inference 降为 hypothesis。不添加来源、不做模糊 URL 匹配、不升级主张。原始输出以每次请求的私有审计草稿保留；来源撤回会清理派生数据。严格校验仍是发布门槛。
- 来源限流时遵守 Backoff，可从6小时内的本地许可信号中检索候选材料，保留原采集时间并明确缓存身份；不把缓存说成本次新采集。界面及导出报告显示来源失败与缓存覆盖。
- 发现残留的开发监听进程在端口占用时仍启动引擎并改写运行任务。修复启动顺序：先成功监听端口，再打开数据库及恢复任务；正确处理 Express 5 listen 回调的 error。重复服务必须退出，不运行第二个 worker。现已清理重复进程，前端与 API 分别运行。
- 数据库列表按插入顺序读取，避免随机 ID 导致任务／费用排序混乱；重试清除旧错误提示。
- 机会卡片组件移至 App 外，避免后台轮询时整卡重挂载、键盘焦点和点击目标丢失。
- 研究导出时间按本机时区呈现并注明时区；采集原始时间保留 ISO UTC。

## 验收边界

真实供应商调用、官方 API 材料、导出及私人项目软件流程均通过。报告保持未评级／低可信／R0／L0。题目和宏观背景不能验证用户行为或付费；不以模型输出替代客户实证。用户未填写费率时费用金额为未知，仍保留 token 用量。

无破坏性 SQL 迁移，增加审计与来源缓存标识字段。回退应先停服务并备份 `.data/`，包括 vault；不能删除私有记录来掩盖失败尝试。
