# ADR-004 — 报告、引用与孵化快照一致性

状态：已实施。

根据用户要求检查真实研究、报告引用与孵化工作流，新增下列一致性约束：

1. Markdown 报告由服务端统一渲染，携带章节 claim ID、逐字摘录、真实链接、署名、许可、原日期、采集时间和模型／方法版本；移除真实报告中的演示文案。按用户当前查看的版本导出。
2. 孵化项目记录 source_report_id/source_version/source_as_of/source_evidence_ids；历史版本进入孵化时使用该版本，不静默改成最新版。已有项目不被重研覆盖。
3. 已复盘状态必须始终有非空结果，包括清空旧结果、空白及不提交 stage 的局部更新。
4. 来源撤回后拒绝导出及新建项目；版本号按所有历史记录递增，避免覆盖撤回记录。来源撤回同时清理私有分析草稿和排除材料。
5. 至少一条可逐字核验的实际引用才能发布分析，零引用不能被标记为引用已校验。模型输出先在私人草稿保存，验证失败不发布。
6. 增加可审计标题词面相关性筛选，明显没有检索词匹配的记录不纳入分析。AI 规划可以提供歧义排除词；宏观数据仍只作背景。词面匹配不是语义验证或市场证明。

没有更改付款或决策准备的保守边界，没有将软件验收当作客户研究结果。无破坏性 SQL 迁移，历史项目缺来源版本字段时保持原状态。
