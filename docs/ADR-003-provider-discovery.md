# ADR-003 — 实时模型同步、连接诊断与可选费用边界

状态：已实施。根据用户反馈：缺少模型同步与测试入口；费用边界不应必填。

- POST `/api/research/provider/models`：使用当前表单的服务地址及密钥，或同地址已保存密钥，实时请求 `GET /models`；保留 ID、创建时间、归属，去重排序并记录同步时间。不硬编码“最新模型”，不自动替换用户选择。不兼容标准列表时明确提示可手填；不把不完整分页报作最新全量。
- POST `/api/research/provider/check`：只检查网络、鉴权及模型列表，不发起推理；不要求模型 ID、费率、预算或先保存。
- POST `/api/research/provider/test`：接受未保存的完整连接草稿，实际发送最小 JSON 请求，返回模型、用量、延迟、可估算费用；测试不覆盖已保存配置。
- 服务地址变更而未填写新密钥时不沿用原地址密钥。密钥不回显；模型目录只缓存安全公开字段。
- 四个 USD 字段均可留空，数据库及接口为 null；留空时不启用对应美元限额，不阻止正常研究。无费率时保留 token 用量、费用记 null 并显示“未知”，不默认为免费或零成本。费率可为零以明确表示已知免费服务。
- 若用户主动设置美元限额，必须有相应费率才能进行可靠预留，否则显示诊断；不静默忽略已设置的限额。未知历史调用仅影响其所在的金额预算范围。
- 前端测试结果持久显示在当前页面，配置发生修改后清除过期诊断。费用配置默认折叠，模型搜索、选择与手动输入并存。

覆盖 ADR-002 中“费率与金额预算必须先设置才能调用”的实现边界；其余来源与研究规则保持不变。供应商自定义计费机制可能未返回费用；配置费率为用户输入，最终金额以供应商账单为准。
