# ADR-001 — 本地验证版实现边界

状态：已实施；生产架构仍按原始 PRD 后续推进。

用户要求按 PRD 完成产品，并确认品牌 NEDVEO／苗头及双语 slogan。附件中的 Agent 启动指令作为参考，不覆盖本次实际请求。

空仓库首先提供可实际运行、可审查的本地完整交互闭环。选择 React/Vite + Express + Node SQLite，减少启动服务依赖。生产所需 PostgreSQL/RLS、持久化队列、模型路由与授权数据连接器尚未替代或取消。

数据模型采用 tenant/kind/id 的持久化记录表，当前固定本地 owner、只绑定回环地址。不可作为已有身份验证和生产多租户系统发布。所有预置机会和证据都是显式标注的虚构样例，不在没有信源授权和采集的情况下冒充实时发现。

研究计划是规则式问题分解，不是 AI 研究结果；无模型调用、无计费。导入材料默认私人、未核验，保留用户输入的来源。点分保持 null。潜力标签仅用于演示，证据置信、准备等级和付费等级独立展示。

后续逐阶段实现原始 B0–B7 验收门，不将 UI 完成算作真实采集、运行质量或市场验证通过。
