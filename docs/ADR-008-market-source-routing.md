# ADR-008 中国市场来源路由与覆盖预检

用户的中国市场题目出现行业Feed和竞品0条、美国源跳过、英文问答2条。实际根因：未登记任何行业Feed；初始竞品档案只有海外财务工具；只用英文规划匹配，漏掉中文词；采集的2条英文问题还被相关性筛选排除，并不能用于中国需求结论。

本次变更：

- 新增阿里云百炼、有赞AI、火山方舟、百度AppBuilder中国官方产品档案，严格保留公开页面读取、robots/noai、少量事实摘录和访问失败记录。登记不等于本次读取成功。
- 竞品匹配合并原问题与英文规划，规范 e-commerce/ecommerce；短词 AI 用边界匹配，避免命中 retail。优先同市场档案，其他市场档案不自动冒充本地；比较关系保留为待验证替代方案。
- 中国任务与周期任务默认排除US-only来源，旧任务保留原选择及不适用原因。POST覆盖预检只读、无模型调用；查看者也可读取。
- 未配置、未匹配、检索为空、访问失败、部分成功分别存储，不再统一completed/0。任务展示中文来源名，区分采集数、实际入选数和境外背景限制；导出同样保留。
- 中文报价支持人民币及全角符号的必要摘录，动态0元不解释成免费；中文摘要另有限定字符预算。
- 官网逐站失败可复用6小时内材料，保留原采集时间，不更新官网核对时间。没有缓存就如实失败。
- 真实运行暴露商业阶段复制已降级主张ID的问题：现在递归过滤输入中的无效ID，并用可引用ID枚举约束输出合同。复用核心草稿时重新校验。官网逐字引用只允许真实提取片段，采集器的“标价非付款”等注释不能当厂商原文。

没有破坏性迁移、没有新密钥、没有绕过访问限制。4个官网档案由已有种子机制追加，不覆盖用户已有或停用记录。仍未接入中国商家投诉／评论／交易库，不以官网文案证明付费需求；许可Feed仍需登记实际授权来源。

核实的官方入口：[百炼](https://www.aliyun.com/product/bailian)、[有赞AI](https://www.youzan.com/solutions/ai)、[方舟](https://www.volcengine.com/product/ark)、[AppBuilder](https://ai.baidu.com/tech/AppBuilder)。实际网络验收与引用检查见 progress.md；可访问性是本次环境结果，不作永久承诺。
