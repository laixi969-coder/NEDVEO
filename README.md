# NEDVEO · 苗头

**See the Need. Find the Opportunity.**\
**好生意，早有苗头。**

支持本机模式与认证自托管模式的真实商机研究工作台：真实市场 API／竞品官网 → 来源簇去重 → 核心研究与商业分析 → 引用完整性验证 → 版本化研究 → 孵化实验。默认没有虚构机会；只有测试使用 SHOW_DEMO=1。

## 自行部署

已提供 Dockerfile、PostgreSQL/Caddy Compose、登录及工作空间隔离、迁移和备份脚本。部署步骤见 [DEPLOYMENT.md](docs/DEPLOYMENT.md)。本轮没有代为部署。

**完整 PRD 尚未全部验收**，逐项实现与缺口见 [PRD_STATUS.md](docs/PRD_STATUS.md)。20个行业入口和可扩展来源不等于已获得全行业资料授权。Docker 镜像和公网 TLS 尚待你的部署环境验证。

## 本机启动

推荐 Node.js 24 LTS（最低22.19，生产镜像使用24）：

```sh
npm ci
npm run dev
```

前端默认 http://127.0.0.1:5173 （占用时看终端提示）；API 为 4311，仅本机访问。

```sh
npm run build
npm start
```

生产构建的本地入口 http://127.0.0.1:4311 。此命令默认仍是只监听回环的本机模式；公网认证部署需按部署手册设置。

## 开启真实 AI 研究

1. 打开「账户与配置」（`/?view=integrations`）。
2. 填入 OpenAI／兼容服务的 HTTPS API 基址和 API 密钥，直接点击「同步最新模型」或「测试连接」，无需先填写模型或保存。
3. 从服务实时返回的列表搜索、选择模型，也可以手填模型 ID。列表按服务提供的创建时间优先排序，不自动判断模型是否适合文本研究，不自动替换当前选择。
4. 选择 Responses 或 Chat Completions。若兼容供应商使用 `max_tokens`，切换输出额度参数。JSON Schema 需供应商支持；也支持 JSON object 与仅提示约束。
5. **费用边界全部选填。** 留空不设置美元上限，token 用量照常记录，金额显示「费用未知」。填写费率后可以估算金额；若主动设置美元上限，需要费率才能执行预算检查。测试连接不发起模型推理；「测试模型响应」会产生少量供应商调用费用。
6. 可先点击「测试模型响应」验证当前草稿，结果在页面保留并显示延迟、模型和用量。确认后保存配置。密钥不回显；改变服务地址时不会隐式转发原地址的已存密钥。
7. 新建研究，选择市场／来源；英文关键词可手动指定，也可由模型从中文问题生成。进入「我的研究」查看阶段、覆盖、费用、引用与失败原因。

没有模型时仍可采集并保存真实 API 材料，任务进入「等待模型配置」。配置后点击「重新执行」。失败的计费请求不会自动重试。真正执行模型调用需要你自己的有效凭据与供应商余额。

私人材料只在本次明确选择并勾选发送授权后进入模型。模型服务的数据处理政策由所选供应商决定。

## 真实信源与边界

| 信源 | 获取内容 | 不支持的推断 |
|---|---|---|
| Crossref（选填） | 标题、DOI、出版机构、出版日期 | 题目不是论文结论，学术研究不是客户需求验证 |
| Stack Exchange（默认） | 按问题选择社区；经脱敏的许可正文摘录、日期、署名与回答状态 | 英文社群及历史样本偏差，求助不是付款 |
| 行业许可 RSS / Atom | 用户登记并确认许可的行业摘要 | 未登记时明确显示覆盖缺口 |
| 竞品官网（默认） | 登记官方产品／定价页、有限事实摘录、版本快照与变化提醒 | 标价非成交；动态价格、税费、周期和收入可为 UNKNOWN |
| CFPB（默认，适用时） | 美国消费金融投诉分类、公司、回复；不保存个人叙述和地址 | 消费者主张非裁决，不能推算发生率或商家采购意愿 |
| USAspending（默认，适用时） | 美国政府合同采购方、供应商、描述及原始金额口径 | 获授／义务金额非实际现金、利润或本产品收入 |
| 中国工信部（中国） | 官方近期产业公告标题、链接；遵守 robots，不转载正文 | 目录非全站搜索；政策标题不能证明需求 |
| METI（日本） | 经济产业省官方 Atom 标题、摘要与日期 | 近期订阅窗口；政策与动态不是客户验证 |
| TED（欧洲） | 公开采购公告、买方所在国、公告类型与估算金额 | 公告及估值非成交；不代表整个欧洲市场 |
| Find a Tender（英国） | OCDS 最近14天最多100条更新公告的关键词筛选 | 非全库搜索；取消、招标、获授与付款须区分 |
| Federal Register（美国） | 监管摘要、机构、公告类型、发布日期 | 草案非生效规则，须核对正式法律文本 |
| FDA 食品／药品召回（美国，相关行业） | 产品、企业、原因、分类、状态及召回编号 | 不是需求、付费或发生率；排除个人地址及 GMDN |
| World Bank WDI（选填） | 按问题选择老龄化、互联网覆盖或劳动参与率 | 宏观背景不能证明微观场景有市场 |

「竞品情报」可登记其他行业官网，按标签匹配研究；内置 32 个真实官方页面档案，覆盖中国、美国、日本、欧洲及全球方案，涵盖财务、电商、制造、农业、教育、医疗、客服、协作等场景。档案为候选登记，尚未采集时没有已核对事实。采集前检查 robots 和页面限制；无法合法读取时记录失败及缺口，不绕过访问限制。最多尝试10个匹配候选、收集4份有效材料；本地优先，读取失败继续尝试适用全球方案，全球材料不作为本地需求验证。美国投诉与采购不用于其他国家的本地结论。

研究前可点击「检测实际信源（不调用 AI）」：尊重勾选范围，显示逐源计数、逐站失败、网络错误和限流。仅保存检测摘要，不生成报告或调用模型；重复检测有60秒缓存。新增适配器与实网验收范围见 [ADR-009](docs/ADR-009-expanded-public-sources.md)。

每条保留原链接、来源、日期、许可、必要署名。论文摘要与正文不采集。检索相关性、来源语义支撑仍需复核。来源停用、许可到期或材料删除时，派生报告会被撤回并清理相关内容。授权记录和保存期限见配置页及 ADR-002。

## 可用功能

- 真实研究任务后台队列、状态与逐源失败记录、取消、手动重试。
- 价值—共识—模式、反证、未知、最小实验；逐主张 evidence_id 与原文摘录校验。
- 商业判断：使用者／受益者／支付者／预算人／决策人，细分切入口、现有方案缺口、第一渠道、收入路径、成本、指标与停止条件。
- 竞品官方事实、标价原文、快照与变化提醒；不自动改写历史研究。
- 两阶段模型研究，避免单次长报告截断；相同方法和证据的失败重试可复用已核验核心。
- 机会库、市场／行业搜索与筛选、当前／未来双轨、关注、私人孵化项目。
- 研究版本快照、Markdown 导出含来源、主张和许可。
- 私人材料导入／去重／删除与派生清理。
- 每日跟踪（应用需保持运行），研究新版本站内事件。
- 密钥本机 AES-256-GCM 加密，费用预留／结算／保守未知费记账与预算熔断。

真实研究默认「未评级／低可信／R0／L0」；这表示仅有可追溯材料和待验证假设，不是商业失败。自动引用校验只证明摘录存在，不能证明推论正确。对外联系、付款和实验不会自动执行。

## 存储、部署与回退

React/TypeScript/Vite + Express + Node SQLite。`.data/nedveo.sqlite` 保存记录；`.data/provider.enc` 与 `.data/vault.key` 保存加密配置和 0600 本机密钥。备份时保护整个目录。当前用户若已具备本机文件读取权限，也能解密配置，这不是外部 KMS。

可设 `PORT`、`DB_PATH`、`VAULT_DIR`。不在 Git 中提交 `.data/` 或密钥。前端使用 Google Fonts，可离线回退本地字体。

回退前停服务并备份 `.data/`。恢复旧代码后执行 `npm ci && npm run build`。旧演示版本不能继续操作新增的真实研究对象；回退以备份为准。删除 `.data/` 会不可逆清除本机私人研究及模型配置。

## 真实研究验收

保存模型配置后，可运行：

```sh
node scripts/live-acceptance.mjs
```

此命令使用当前配置，实际调用模型，执行跨语言规划、来源采集、分析、引用验证、导出和私人项目创建。会产生供应商调用费用。孵化验收只测试软件阶段流转，最终保留「待验证」，不会写入虚构的客户实验或付款结果。报告与验收记录仅保存到 Git 忽略的 `.data/acceptance/`。未保存模型时明确退出，不生成假报告。

市场研究的无论文／宏观依赖验收：

```sh
node scripts/commercial-acceptance.mjs <任务ID>
```

此脚本只等待和核对该任务，导出 `.data/acceptance/commercial-report.md`，不会自行创建或重新执行付费任务。任务失败会明确退出；真实运行记录见 `docs/progress.md` 和 ADR-006。
